# Technical Note 026 — V150

Source: supplied NT_E_KUATIA_026_MT_V150.

Date: 06/06/2025.
Test availability: 09/06/2025.
Production availability: 16/06/2025.

The note documents corrections/adjustments to Manual Técnico V150.

Areas explicitly shown in the supplied note:
- XML field observations for item information fields E704/E705.
- XML field observation for public-procurement group E020-E029.
- removal of specified validation rules for public procurement information.
- changes affecting B2G-related validation behavior.

## Rule

When implementing public-procurement/B2G XML or validation logic, consult this note together with the applicable Manual V150/XSD. Do not rely only on an older copy of the Manual.
