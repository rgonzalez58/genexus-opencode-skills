# Technical Note 027 — V150

Source: supplied NT_E_KUATIA_027_MT_V150.

Date: 09/03/2026.
Test availability: 09/03/2026.
Production availability: 09/03/2026.

The note documents corrections/adjustments to Manual Técnico V150 for the event of nomination of electronic invoice.

Fields changed include:
- `iTipIDRec` — receiver identity-document type.
- `dDTipIDRec` — description of the identity-document type.

The note lists receiver identity types such as Paraguayan ID, passport, foreign ID, residence card, diplomatic tax-exemption card and other.

## Rule

When generating or validating the nomination event, apply the Technical Note 027 changes in addition to the base Manual V150.
