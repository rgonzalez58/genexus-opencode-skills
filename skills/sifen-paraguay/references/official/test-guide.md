# Guía de Pruebas para e-kuatia

The supplied guide describes minimum testing for the SIFEN test environment.

Coverage includes:
1. Communication and mutual authentication.
2. DE transmission.
3. SIFEN validations.
4. Approved/rejected results.
5. Event registration and association.
6. DTE and event consultation.
7. KuDE generation/transmission for each applicable DTE type.
8. Error DE scenarios.
9. QR validation.

## Environment

The test environment provides test data and services for development. Documents generated there do not have legal value. Production is the operational environment for enabled electronic invoicing, and approved DTEs have the corresponding tax/legal effect described by DNIT.

## Skill rule

Use this guide as the acceptance-test baseline, not as a substitute for the Manual/XSD.
