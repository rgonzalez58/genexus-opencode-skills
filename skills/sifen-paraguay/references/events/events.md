# Eventos

El Manual V150 tiene un capítulo específico de Gestión de Eventos. La guía de pruebas contempla registro de eventos y consulta de DTE con eventos asociados.

Al implementar un evento:

1. identificar el tipo de evento;
2. validar versión y XSD de evento;
3. revisar Notas Técnicas vigentes;
4. validar condiciones de estado del DTE;
5. registrar respuesta de SIFEN;
6. mantener trazabilidad por CDC/protocolo/evento.

La NT 027 cargada modifica el evento de nominación de Factura Electrónica en campos de identificación del receptor; debe tratarse como modificación posterior al Manual V150.
