## Evidence policy

The Manual Técnico is the primary broad technical reference. Technical Notes amend/correct it. XSD/XML structure files are structural references. The test guide defines testing coverage. The best-practices document gives practical guidance for asynchronous lot handling.

Do not treat a project implementation as official documentation.
